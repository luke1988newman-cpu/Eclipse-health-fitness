# Eclipse Health & Fitness website

Static site for Eclipse Health & Fitness, 140 Station Rd, Hesketh Bank, Preston PR4 6SR, including the Ministry of Fitness section.

- `index.html` is the whole page. Photos and the gym video are in `assets/`.
- This is a temporary preview. `robots.txt` and the `noindex` tag block search engines. Remove both at launch and set the real domain's canonical URL.
- Hosting: Netlify, deploying automatically from the `main` branch. No build step; publish directory is the repo root.
